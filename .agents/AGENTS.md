## Discross Sentry & MCP Configuration
- For Sentry MCP calls regarding Discross, use organization slug `larsenv` and project slug `discros`.
- Sentry access token is configured in `/Users/larsen/.gemini/config/mcp_config.json` under `@sentry/mcp-server@latest`.
- The Sentry DSN is read from `SENTRY_DSN` in the local `.env` file (never commit it).
